A personal Learning Operating System, not four apps glued together.

Upload a textbook or a photo of a whiteboard. It gets parsed, searched, and turned into a concept graph — then into lessons, flashcards, a study guide, grounded chat with citations, and practice questions with hints and error feedback. Everything traces back to exactly where it came from.

The loop this product is built around
Source→ Concept→ Lesson→ Question→ Attempt→ Error→ Mastery→ Planner→ Next session
Four patterns, one domain

What it replaces

Each of these exists as a separate product today. Here they share one database, one concept graph, and one interface instead of four disconnected silos.

01

Notebook / RAG

Upload PDFs, slides, photos, web pages, and YouTube videos. Every answer cites the exact page or timestamp it came from.

02

Curriculum & practice

Topics, lessons, definitions, flashcards, question banks, and past papers — generated from your own sources, not a generic template.

03

Adaptive planner

Exam dates, availability, and evidence of what you actually know feed a schedule that reoptimizes without churning your calendar every day.

04

Deep training

A depth scale from recall to olympiad-level transfer, gated on evidence — not on having merely read a chapter.

Local-first, cloud-ready

Stack

Runs entirely on a laptop via Docker Compose — no Kubernetes, no Kafka, no mandatory cloud dependency. The same code scales to a VPS or managed cloud later.

Frontend

  • Next.js App Router
  • TypeScript + Tailwind
  • TanStack Query

Backend

  • FastAPI modular monolith
  • SQLAlchemy 2 + Alembic
  • Celery + Redis

Data

  • PostgreSQL + pgvector
  • MinIO / S3-compatible storage
  • Postgres full-text search

Intelligence (later phases)

  • Docling + PaddleOCR
  • BKT + FSRS + OR-Tools
  • Model-agnostic AI router

Why this page is static and the app isn't

GitHub Pages only serves static files. It cannot run the FastAPI backend, PostgreSQL, Redis, or Celery workers this project needs — so this page is documentation, not the product.

The real application lives in apps/web and apps/api in the repository. Run it locally with Docker, or deploy it to a host that supports servers — Render, Railway, Fly.io, or a VPS. 

git clone https://github.com/Apepsis/Adaptative-Learning-OS
cd Adaptative-Learning-OS
cp .env.example .env
make dev
# web:  http://localhost:3000
# api:  http://localhost:8000/health/ready
